# Security policy

## Supported versions

Security fixes are applied to the latest published release candidate or stable
release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private
**Security > Report a vulnerability** form for this repository. Include the
affected version, reproduction steps, impact, and any suggested mitigation.

Please allow maintainers reasonable time to investigate and publish a fix before
public disclosure. GestureOS processes camera and microphone input locally and
does not intentionally transmit telemetry or media.
